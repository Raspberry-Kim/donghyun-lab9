# 동현크 v0.01

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23914027.svg)](https://doi.org/10.5281/zenodo.23914027)

동현랭으로 목숨과 변신을 정하고 나서는 횡스크롤 액션 플랫폼 게임이다.
동현 시리즈의 아홉 번째 작은 실험이다. 주인공은 실험실의 강아지 포동이다.

- 모드: 1인용 플랫폼 스테이지만 있다. 원작에 있던 오락실 미니게임은 두지 않았다.
- 스테이지 1 「포동이의 첫 산책」: 들판 → 동현워 성벽 → 동현전 공장지대의 세 구역, 가로 200칸.
- 변신 5종: 전차(동현전) · 기사(동현워) · 헬기(동현콥) · 둠(동현둠) · 초파리(동현초). 한 판에 네 가지까지 들고 간다.
- 적 6종: 라이언·슈슈(동현파), 보병·전차(동현전), 창병·기사(동현워).
- 화면: 320×192(가로 20칸 × 세로 12칸, 16px). 동현전·동현워 창 크기에 맞춘 가로로 긴 비율이다.

## 동현크 출전 규약

| 변수 값 | 뜻 | 범위 |
|---|---|---|
| 1 | 목숨 수 | 1–99 · 0은 무적(무한) · 기본 3 |
| 2 | 변신 추가 | 1 전차 · 2 기사 · 3 헬기 · 4 둠 · 5 초파리 · 여러 번 써서 네 가지까지 |
| 3 | 스테이지 | 1 (지금은 하나) |
| 6 | 출전 | 마지막에 둔다 |

`뿡뿡 번호~뿡뿡뿡` 다음 줄에 `뿡뿡 값~뿡뿡뿡`을 출력하는 식으로 쓴다. 예제는 목숨 → 변신 → 스테이지 순서로 적었다.

## 조작

← → 달리기 · X 점프(길게 누르면 높이, 초파리는 2단 점프) · Z 공격 · S 변신 바꾸기 · A 지금 모습 설명 · Enter 메뉴(계속·변신 설명·포기) · M 효과음. 동현전·동현워와 같은 키 배치다. 좁은 화면과 터치 기기에서는 화면 버튼이 나온다.

## 규칙 요약

- 체력은 모습마다 다르고(기본 3), 맞으면 1 줄며 잠깐 무적이 된다. 체력 0이면 목숨 하나를 잃고 구역 입구에서 다시 시작한다.
- 라이언·슈슈·보병·창병은 밟을 수 있다. 전차와 기사는 공격으로만 쓰러뜨린다.
- 점수: 적 100–400, 뼈다귀 50, 깃발 1000 + 시간 보너스 + 남은 목숨 × 500.

## 파일

- `src/` 원본(donghyun.js 실행기 · sprites.js 도트 · data.js 자료 · engine.js 규칙 · render.js 화면 · examples.js 예제 · sfx.js 효과음 · app.js 화면 연결)
